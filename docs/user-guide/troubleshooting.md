- "No results found": check the place name or try a code; check whether that data has been incorporated yet ([Data releases](../data/data-releases.md)).
- Unexpected or incomplete answers: rephrase, narrow the question, or name the relationship. If the conversation has become long or muddled, clear it with the eraser (see `user-guide/managing-conversations.md`). The error "The chat agent was unable to generate a response. If your chat history is not relevant to the current request, you can try clearing your chat history..." points to the same fix.
- Map shows nothing: check that View on Map was used, and the zoom and layers.
- Slow responses: expected for complex questions. Confirm typical timing.
- Where to get help.
