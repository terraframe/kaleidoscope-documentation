# Saving a query

When you view an answer on the map, you can save the query behind it. Saved queries are listed in the sidebar, so you can map their results again later without asking the question again.

## Saving a query

1. On the map, click **Save Query** at the top left.
2. In the **Save Query** window, enter a **Name**. A name is filled in for you, such as "Mapped chat query (10935)", with the number of results in brackets. You can replace it.
3. Click **Save**.

![The Save Query window over the map, with a Name field filled in with "Mapped chat query (10935)", and Cancel and Save buttons.](/img/screenshots/save-query.png)

The query is added to the **Saved Queries** tab in the sidebar. On the map, the **Save Query** button changes to show the query's name, and in the chat, the answer shows a **Saved Query #N** button.

## Opening a saved query

1. On the chat page, click the **Saved Queries** tab in the sidebar. Each saved query shows its number and name, the number of results, and the date and time it was saved.
2. Click the map icon (**View on Map**) on the query. The map opens with the same results as when you first clicked **View on Map**.

![The Saved Queries tab in the sidebar, listing two saved queries, "#1 Mapped chat query (10935)" and "#2 FloodScenario (2)", each with its number of results, the date and time it was saved, and map, pencil and trash icons. In the chat, an answer shows a Saved Query #1 button next to View on Map.](/img/screenshots/saved-queries.png)

## Moving between a saved query and its answer

* To see the answer a saved query came from, click the query in the **Saved Queries** tab anywhere other than its icons. The chat opens at that answer.
* To find the saved query for an answer, click **Saved Query #N** next to **View on Map** on the answer. The query is shown in the **Saved Queries** tab.

## Renaming or deleting a saved query

* In the **Saved Queries** tab, click the pencil icon (**Rename query**) on the query, type the new name and press Enter. Press Escape to cancel. To delete the query, click the trash icon (**Delete query**) and confirm.
* On the map, click the button with the saved query's name to open the **Saved Query** window. Click **Rename** to change its name, or **Unsave** to remove it from your saved queries.

:::info
Saved queries are stored in your browser's local storage, like your chat history. They're only available in the browser you saved them in, and clearing your browser's data deletes them.
:::
