- **Good questions:** about data in the current release; counts, totals, "which ones", "what's affected".
- **Out of scope:** data not yet incorporated, real-time conditions, forecasting, opinions or recommendations not grounded in the data (this will evolve with the reporting use case).
- When there's no data, the intent is that Kaleidoscope says it couldn't find results instead of guessing. Test this in the app first (DOC-ISSUES.md).
- Result limits: queries return up to 100 results. Decide whether users should be told this.
