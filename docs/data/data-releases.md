# Data releases

Kaleidoscope's data isn't fixed. USACE staff add and update datasets in [Geoprism Registry](https://docs.geoprismregistry.com/version/v2.0.0/curate), and those changes reach Kaleidoscope in **data releases**.

:::info
The release process is still being defined. Once it's in place, this page will describe how often releases happen, what they include, how to request new data, and link to a catalog of the data Kaleidoscope includes.
:::

## What each release will record

Each release will list:

* Its release identifier and date.
* The datasets added, updated or retired.
* The Source Authority responsible for each dataset.
* The geographic area each dataset covers.
* Any new types of objects or relationships, which make new kinds of questions possible.
